# Entrega 1 — Fundamentos (Semana 01)

Entregável da Semana 01: variáveis, tipos primitivos, operadores e entrada/saída de dados.

## Conteúdo

| Arquivo | O que faz |
| --- | --- |
| `desafio_1_calculadora_troco.py` | Recebe o valor da compra e o valor pago e calcula o troco. |
| `desafio_2_media_notas.py` | Lê 3 notas via `input()` e imprime a média com 2 casas decimais. |
| `desafio_3_conversor_tempo.py` | Recebe um valor em segundos e converte para horas, minutos e segundos. |
| `desafio_4_calculadora_desconto.py` | Recebe o preço de um produto e o percentual de desconto e imprime o preço final. |
| `desafio_5_par_ou_impar.py` | Recebe um número inteiro e informa se é par ou ímpar usando o operador `%`. |
| `desafio_6_inversor_nome.py` | Recebe um nome e imprime invertido usando slicing `[::-1]`. |

## Como executar

```bash
python desafio_1_calculadora_troco.py
```

Cada arquivo é independente — basta rodar com `python <arquivo>.py` e seguir as instruções no terminal.

## Padrões

- Nomes de variáveis em `snake_case`, seguindo a PEP 8.
- Saída formatada com f-strings.
- `input()` sempre convertido com `int()` ou `float()` antes de operações numéricas.
- Todos os desafios foram executados e rodam sem erro.
