## Origem

O projeto começou como um arquivo **Figma Make** ("Wireframe mobile low-fidelity",
fileKey `NdDqbymWZZKF6Jm1O49iof`), que passou por 4 versões — de wireframe cinza a
app dark + roxo. O código atual não é um port daquele arquivo: a direção visual da
v4 foi mantida, mas a estrutura foi reescrita. A auditoria completa do que mudou
está no [README](../README.md#o-que-mudou-em-relação-ao-figma-make).
